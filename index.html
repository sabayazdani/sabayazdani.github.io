Who I am

About

I'm a software developer in Toronto. I build AI products end to end, from the Python and Java services that do the work to the React interfaces people use.

Realest

A voice agent that phones rental listing agents on a renter's behalf to check availability, fees, parking, and pet policies, built with a team of four at the AI Tinkerers hackathon. I built the outbound calling in Python with FastAPI and asyncio, so many calls run at once with per-call timeouts and fallbacks. I also built the email fallback for calls nobody answers, with a guard so no message goes out twice, and the LLM pipeline that turns each call transcript into structured data used to re-rank the listings.

Maridian

A decision layer for a bakery's production floor, built at the TMLS Agentic Hackathon. It takes defect events from the line, runs them through LLM agents for triage, action planning, and scoring, and streams live updates to a React and Next.js dashboard. Nothing customer-facing happens until an operator approves it, and every decision is logged. I built the FastAPI backend, the agent workflow, and the Server-Sent Events stream, and deployed it to Vercel and Railway.

Gradify

The AI-assisted grading platform I build and maintain for senior Computer Science courses at York University. Claude and Gemini propose scores for handwritten and PDF work, and instructors approve each result before students see it. It runs on React, Spring Boot, and PostgreSQL.

Geometric Burning Under L1 and L∞ Metrics, and Beyond

Shahin Kamali, Saba Yazdani

Approximation algorithms for burning a point set under the L1 and L∞ metrics, including a 1.75 + ε approximation for anywhere burning, with the results extended to every Lp metric.

CEEA 2026

Comparative Evaluation of Large Language Models in Computer Programming Education

Melina Najimi, Saba Yazdani, Marzieh Ahmadzadeh Co-first author

Compares six large language models on formative feedback for introductory Java programs, measuring correctness, completeness, specificity, prompt adherence, clarity, and latency. No single model led on every criterion.

Read paper
EDULEARN 2025

The Paradox of Generative AI in Programming Education

Saba Yazdani, Melina Najimi, Marzieh Ahmadzadeh Co-first author

Compares 698 students who took an advanced object-oriented programming course before generative AI with 203 who had access to it. Scores fell on most topics but rose on recursion, and basic submission errors such as file-naming mistakes increased.

Read paper

Beyond Grades: A Java Auto-Grader for Scaffolded Learning

Introduces Gradify, a Java auto-grader that lets students test their code against a hierarchy of increasingly complex test cases, with separate interfaces for students and instructors.
